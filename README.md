# منظومة النمو — موقع دراسة حالة

موقع عربي RTL مبني بـ React + Vite + Tailwind CSS + Framer Motion + Lucide.

## التشغيل

```sh
npm install
npm run dev
```

لإنشاء نسخة الإنتاج: `npm run build` ثم `npm run preview`.

## تعديل الموقع

- الألوان والتدرجات: المتغيرات في بداية `src/styles.css`.
- الاسم، البريد، رقم واتساب، ورابط استقبال النموذج: `brand` في `src/content.js`.
- الخدمات والأسئلة الشائعة: `src/content.js`.
- النصوص الأخرى: ملف القسم الموافق داخل `src/components/`.
- الصور الأصلية المستخرجة من العرض: `public/images/`.

اسم «منظومة النمو» عنوان وصفي، لأن العرض لا يذكر اسم الجهة. لا توجد شهادات عملاء مختلقة؛ استُخدم معرض الحملة بدلًا منها. نتائج الحملة تاريخية وليست ضمانًا لنتائج مستقبلية.

## استقبال الرسائل

النموذج يتحقق من المدخلات، لكنه لا يدّعي الإرسال دون وسيلة استقبال. اضبط `brand.formEndpoint` على خدمة HTTPS تستقبل JSON بالحقول `name`, `email`, `project`, `message` وترجع حالة HTTP ناجحة بعد قبول الرسالة. يجب أن تدعم الخدمة CORS وأن تنفّذ التحقق من البيانات وتحديد معدل الطلبات والحماية من الرسائل المزعجة على الخادم. لا تضع أسرارًا في الواجهة.

بدلًا من ذلك، اضبط `brand.email` لفتح تطبيق البريد برسالة جاهزة. اضبط `brand.phone` بصيغة دولية لتفعيل زر واتساب. حدّث سياسة الخصوصية حسب الخدمة الفعلية قبل استقبال بيانات الزوار.

الخطوط من كتالوج Google Fonts ومضمّنة محليًا عبر Fontsource، دون طلبات خارجية وقت التشغيل. ملف `.npmrc` يضع ذاكرة npm المؤقتة داخل المشروع لتوافق بيئة العمل.
